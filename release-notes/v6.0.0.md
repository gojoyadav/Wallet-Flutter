### ✨ What's New in v6.0.0

**🎨 Material 3 Expressive & Onboarding Architecture**
- 🌟 **Onboarding Experience Renovation**: Transitioned onboarding architecture from a 5-screen sequence to an expressive 8-screen wireframe flow with fluid ambient motion choreography (`Sunny`, `Bun`, `Soft Boom`).
- 🔄 **Dedicated Backup Restore Stage**: Screen 2 introduces instant restore capabilities for returning users with dedicated file picker integration and automated success state transitions.
- 👤 **Separated Personalization Journey**: Decoupled user avatar image cropping and name entry into dedicated, focused setup stages with contextual guidance.
- 🎨 **Adaptive Color Tokens & Palette**: Introduced the 6-swatch color system (`#E7702B`, `#F1FAEE`, `#A8DADC`, `#457B9D`, `#1D3557`, `#0C1A2F`) supporting dynamic Monet color schemes and fixed theme presets.
- 🛡️ **Enhanced Permissions & Privacy**: Redesigned permissions overview card and streamlined offline-first security highlights.
- 🚀 **Dynamic Welcome & All Set Transitions**: Restyled "Welcome to Wallet" dynamic primary pill and full-screen circular reveal launch animation into the financial dashboard.
